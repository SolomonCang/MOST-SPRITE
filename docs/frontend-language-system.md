# MOST-SPRITE 前端语言系统

前端支持 `zh-CN` 与 `en-US`，默认使用中文。用户选择保存在浏览器本地偏好中，刷新和路由切换后
继续生效；切换语言不会修改任何权威业务数据、设备状态或产品内容。

## 实现边界

- 集中词典位于 `frontend/src/i18n/translations.ts`。中文词典定义完整键集合，英文词典必须满足同一
  TypeScript 键类型，缺少或拼错键会导致构建失败。
- `I18nProvider` 提供插值、语言选择和 UTC 日期格式化，并同步更新文档的 `lang` 属性。
- 界面任务、原因、操作、权限、加载和空状态均进入词典；模式、状态码、产品层级、DQ/QC 原因码、
  单位和公开科学列名保留标准英文标识。
- 已知模拟报警可按 `reason_code` 显示本地化解释；未知或未来报警保留后端原文，避免隐藏权威诊断。
- 语言偏好键为 `most-sprite.locale`；主题偏好键为 `most-sprite.theme`。二者都不是业务数据库字段。

## 扩展规则

新增页面文案时，先在中英文词典添加同名键，再通过 `useI18n().t(...)` 引用。不得在业务组件中直接
散落中文或英文自然语言。带数量的文案使用独立单数/复数键；变量通过 `{name}` 插值传入，不拼接
整句。日期必须经 `formatUtc(...)` 格式化并在界面标明 `UTC`。

组件测试覆盖语言切换、文档语言同步和主题切换；Playwright 覆盖偏好在刷新后的持久化，以及中文
观察流程不受语言系统重构影响。
